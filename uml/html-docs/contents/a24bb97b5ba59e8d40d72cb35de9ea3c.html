Attributes

Visibility Name Type Description
protected DICE_FACES List<List<String>>

Constant containing a list of all the faces (interior List) for each dice (exterior List).

The same dices are always used, just randomly positioned, thus the choice of a constant.
private slots Die[][]

Slots contained in the grid. They are ordered as an array of 4x4, in the default version of the grid.
private diceArray Die[]

The Die array that will be used by the slots. The size of the list is 16, in the default version of the grid.
