# Boggle
Projet de développement d'une version virtuelle, en Java, du plateau de jeu Boggle ainsi que son Timer.
Le concept complet est [ici](Boggle_Concept.pdf)

---

### Outils utilisés: 
- ***Uml*** : StarUML
- ***Développement*** : IntelliJ, Maven
- ***Tests*** : JUnit
  
---
